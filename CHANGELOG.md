# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-11-03

### Изменено

- Архитектура фронтенда: переход с Inertia.js 2 на классическое Vue 3 SPA.
- Авторизация: сессионная auth заменена на Sanctum Bearer tokens.
- Backend: все browser-роуты удалены, вся бизнес-логика перенесена в JSON REST API (`routes/api.php`).
- Frontend: Inertia-страницы заменены на Vue Router views, глобальное состояние в Pinia, API-запросы через axios.
- Удалены зависимости `inertiajs/inertia-laravel`, `tightenco/ziggy`, `laravel/breeze`.

### Добавлено

- API-контроллеры для auth, проектов, заметок, вложений, участников, поиска, тегов, настроек и админки.
- `GET /api/tags` — список всех тегов для редактора заметок.
- Скачивание вложений через axios с Bearer-токеном.

### Инфраструктура

- Docker: добавлен сервис `node` для dev (Vite HMR) и prod (сборка assets).
- Dockerfile: удалён assets-stage, frontend собирается исключительно в контейнере `node`.
- Makefile: добавлены `make npm` и `make npm-install`, `make dev` теперь alias для `make up`.
- Обновлены `README.md` и `AGENTS.md` под новую архитектуру и Docker-окружение.

## [1.4.2] — 2026-11-02

### Исправлено

- Права доступа в production-контейнере: `entrypoint.sh` теперь создаёт runtime-директории, устанавливает владельца `app:app` и выполняет команды Laravel от непривилегированного пользователя через `su-exec`. Убрана директива `USER app` из `Dockerfile`, чтобы root мог выполнить настройку прав перед запуском FrankenPHP.

## [1.4.1] — 2026-11-02

### Исправлено

- Кнопка «Назад» в Inertia-приложении теперь возвращает на предыдущую Inertia-страницу, а не на последнюю полную загрузку: middleware `StoreInertiaPreviousUrl` запоминает переходы с заголовком `X-Inertia`.

## [1.4.0] — 2026-11-02

### Добавлено

- Интерактивный котик на доске проектов (`Dashboard`).
- Котик гуляет по экрану, следит за курсором, засыпает, ест рыбку и мурчит при поглаживании.

## [1.3.0] — 2026-11-02

### Добавлено

- Команды `make dev-restart` и `make prod-restart` для перезапуска окружения со сбросом кеша и пересборкой фронтенда.
- Обновлена документация `README.md`: описание новых команд в таблице `Makefile`.

## [1.2.0] — 2026-11-02

### Добавлено

- Ссылка на регистрацию на странице входа (`/login`).

## [1.1.0] — 2026-11-02

### Изменено

- Регистрация стала открытой: любой гость может создать аккаунт по `/register` без инвайта.
- Убрано требование валидного инвайта из контроллера, формы запроса, маршрута и UI.
- Обновлена документация: `README.md`, `app.md`, `.env.example`.
- Тесты регистрации переведены на сценарий открытой регистрации.

## [1.0.0] — 2026-11-01

Первый публичный релиз Noterdam — self-hosted сервиса проектной документации и заметок.

### Добавлено

- Проекты с архивом и удалением, заметки в Markdown с предпросмотром и подсветкой кода.
- Вложения к заметкам: загрузка, скачивание, встроенный просмотр, ограничения по размеру.
- Теги и полнотекстовый поиск по заметкам.
- Разграничение доступа на уровне проекта: роли `owner`, `editor`, `viewer`.
- Шаринг проектов и приглашение участников по email.
- Регистрация по инвайтам, админ-панель управления инвайтами.
- Настройки профиля и пароля, персональные API-токены Sanctum.
- REST API для проектов, заметок и вложений (`/api/*`).
- Тёмная, светлая и системная темы интерфейса.
- Интерфейс на русском языке, Inertia.js 2 + Vue 3 + TypeScript + TailwindCSS.

### Инфраструктура

- Docker-образ на FrankenPHP (PHP 8.3) + MySQL 8.0, dev- и prod-конфигурации Compose.
- Поддержка reverse proxy (Traefik) с корректным `X-Forwarded-Proto`.
- Скрипт резервного копирования БД и вложений с ротацией.
- CI: Pint, Pest, ESLint и сборка фронтенда.
- Сборка и публикация Docker-образа по тегам `v*`.

### Документация

- README с локальным запуском, развёртыванием, настройкой Traefik/Keenetic, бэкапами и обновлением.
- Техническое задание и описание архитектуры в `app.md`.
